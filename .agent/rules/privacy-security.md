# Privacy and security rule

Use `$protect-kineguide-data`.

- Minimize collected and persisted data.
- Never commit secrets or sensitive artifacts; never log credentials, tokens, connection strings, or health payloads.
- Keep raw camera media in the browser.
- Define purpose, consent, access, retention, export, correction, and deletion before storing health data.
- Test denied and failure paths and never claim formal compliance without evidence.
