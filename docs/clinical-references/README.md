# Clinical references

Store citation metadata and summaries of licensed, authoritative clinical sources here. Do not copy restricted publications or turn a language-model output into a clinical rule. Every future safety or exercise rule must link to a traceable source and clinician review record.

The current educational clinical-flow prototype has no approved clinical references. Its API therefore returns `sourceReferences: []`, `reviewedBy: null`, `reviewedAt: null`, and `reviewStatus: pending_clinical_review`. Do not populate a source identifier until an authorized qualified reviewer has approved the exact locale-specific rule and recorded the review metadata.
