# Evaluation plan

Future evaluation will separate technical pose accuracy, usability, language quality, and clinically reviewed safety outcomes. Define protocols, representative consented cohorts, reference measurements, inclusion/exclusion criteria, uncertainty, and failure analysis before collecting data.

No datasets are included. Any future dataset requires provenance, license, consent, de-identification, retention, access-control, and deletion documentation. Model performance must be reported across relevant subgroups without implying diagnostic efficacy.
