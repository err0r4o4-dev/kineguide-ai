# API overview

The initial public Go API exposes liveness, readiness, versioned health, system dependency status, and OpenAPI documentation. See `packages/contracts/openapi/kineguide-api.yaml` for the source contract.

Future API groups will cover authentication, users, consent, assessment, safety screening, exercises, rehabilitation plans, camera sessions, exercise results, pain feedback, progress, and administration. Their creation requires separate domain, privacy, and clinical review.
