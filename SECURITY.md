# Security Policy

This academic prototype does not currently accept public production traffic. Do not open a public issue for a vulnerability or include personal/health information in any report. Contact the repository maintainers privately through a verified university or project channel.

Never commit secrets. Rotate any credential immediately if it is exposed, remove it from active systems, and then follow an approved history-remediation process. Security fixes should receive focused review and regression tests.

KineGuide AI minimizes data, keeps raw camera video in the browser, and separates AI text processing from the primary database. These controls are architectural foundations, not a claim of regulatory certification.
